# tdd-starter fixture

A minimal Node.js project for TDD behavioral evals. Contains `package.json`
(jest), `jest.config.js`, and empty `src/` + `__tests__/` directories. The agent
works in a copy of this directory.

Cases that use it:
- `tdd-001` — implement `parseDuration` from scratch using TDD
- `tdd-002` — fix a bug in a pre-existing `parseDuration` (Prove-It pattern)
- `tdd-neg-001` / `tdd-neg-002` — negative controls (README, mechanical rename)
