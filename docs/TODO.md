# 待验证与维护

只记录当前有效工作；实现与校验已完成的条目不重复保留。任务按明确范围授权后推进，不以补齐清单为目的扩展技能。

## 模型行为证据

- 为非试点技能补代表性真实任务，覆盖正向、邻近负向与异常输入；格式检查不代替实际模型运行。
- 在 Codex 与 Claude Code 的真实安装环境检查隐式发现与语义路由；当前注入式评估不能证明完整宿主路由。
- 对重要工作流重复运行并记录质量、额外动作、耗时与 token；不把强基线同样成功当作失败，也不据单次样本宣称稳定增益。

## 引用资料维护

- 按实际任务核对远端来源健康度、框架 API、许可和工具版本。不要为保留旧示例而引入兼容层。
- 遇到语言、数据库或供应商差异时优先读取当前官方资料；只有反复出现且有验证价值的缺口才沉淀到引用文件。
- 静态安全模式只能提示风险，不能证明第三方技能安全；新增可执行资源需要检查实际行为和权限。

## 维护边界

不增加加权路由、重复文档、厂商专属技能或没有消费者的脚手架。现有技能名与生命周期分类保持稳定；具体扩展必须有真实任务和验收证据。
