# Brand Kit

Generate premium brand-kit overview images that feel like they came from a serious identity
studio — not generic logos, not random mockups, not messy AI moodboards. Every board is a visual
argument for why the brand exists: one strong brand idea, presented as a complete identity system.

## When to use

- Creating brand-guidelines boards, identity decks, or visual-world presentations
- Logo concepting for a new brand or rebrand
- Identity systems that need to scale across UI, print, image, and detail
- Premium brand presentations where the visual system must feel ownable and intentional
- Triggers on "brand kit", "品牌识别", "logo 设计", "品牌系统", "品牌设计"

**Not for:** frontend code (use `frontend-design`); web/mobile screen reference images (use `imagegen-web`/`imagegen-mobile`); image-first frontend implementation (use `image-to-code`).

**Tool note:** use an available image-generation tool — do not bind to a specific product.

## Steps

### 1. Infer brand strategy first

Before generating, think through the brand's meaning — the visual system must be based on
strategy, not decoration:

- **Category & audience:** developer tool, AI assistant, security, gaming, voice AI, compliance, luxury, productivity, etc.
- **Emotional promise & cultural position:** trust level, mood, what the brand should avoid
- **Symbolic metaphor:** pick a logic that fits the category — developer tool → cursor/frame/bolt/scaffold; security → shield/eye/seal/protected core; voice AI → waveform/mic/orb/speech path; luxury → monogram/seal/emboss; productivity → path/check/block/light. Do not pick symbols randomly.

### 2. Choose a visual mode

Pick one mode that fits the brand and commit to it consistently:

- **Dark Developer/Builder** — near-black panels, monospace accents, command lines, cyan/blue/coral/lime accents. Mood: precise, sharp, builder-native.
- **Dark Product/Operator** — black/dark red/amber, glowing UI chips, card systems, reward motifs. Mood: fast, operational, tactical.
- **Dark Nature/Calm** — deep green, lime accent, misty landscapes, soft overlays. Mood: calm, trustworthy, focused.
- **Dark Security/Threat Intel** — black/navy, shield forms, radar lines, red/blue alert chips. Mood: serious, vigilant, precise.
- **Light Editorial/Compliance** — warm ivory, paper texture, small serif labels, seals, deep blue/red/gold accents. Mood: trustworthy, refined, institutional.
- **Luxury/Beauty/Fashion** — ivory/stone/espresso, serif wordmark, embossing, editorial crops. Mood: tasteful, adult, expensive.
- **Voice/Communication** — dark indigo, lilac glow, waveform, mic motif. Mood: fluid, intelligent, intimate.
- **Cultural/Experimental** — halftone, CRT texture, bold accent, poster-style panels. Mood: memorable, creative, controlled.

### 3. Concept the logo

Use one method, or combine two maximum. The mark must be simple, memorable, symbolic, scalable,
ownable, and connected to the brand idea.

- **Monogram + Meaning** — combine the brand initial with a metaphor (K + kite/frame, S + sound wave, A + ascent). Use negative space, cuts, folds, or geometry — not a boring letter icon.
- **Product Action** — turn the product's main action into a symbol (build → frame/scaffold, protect → shield, convert → switch/arrow, speak → waveform). Abstract and premium, not literal.
- **Metaphor Fusion** — combine two meaningful ideas into one reduced mark (owl + drone vision, shield + mountain, moon + waveform). Subtle and readable.
- **Negative Space** — hidden intelligence in empty space (hidden arrow, protected center, cutout initial, eye formed by crossing shapes). Crisp, not clever for its own sake.
- **Construction Geometry** — a mark from a clear system (circles, diagonal cuts, grids, frames, modular blocks, orbital paths, crosshairs).

Avoid: generic lightning bolts, random animals, fake luxury crests, copied famous marks, overcomplicated symbols, clipart icons, meaningless sparkles.

### 4. Compose the board

Default to a **3×3 grid** (or 2×3, 2×2, 1×3, 4×2) on a presentation canvas with strong gutters,
clean alignment, and refined negative space. Give the board rhythm — not every panel equally loud:

- **Logo cover** — large logo + wordmark, minimal title, strong negative space
- **Logo construction** — symbol breakdown, grid, geometry, or negative-space logic
- **Digital application** — browser chrome, app header, terminal, app icon
- **Brand essence** — one short tagline, large readable typography, sparse composition
- **Color system** — swatches, gradient strips, palette cards
- **Typography** — large type specimen, alphabet row, or primary/secondary pairing
- **Physical application** — card, badge, poster, label, seal, packaging
- **Image direction** — cinematic landscape, product crop, halftone poster, editorial scene
- **System detail** — UI chips, input bar, command line, icon row, component strip

A 2×3 layout works for a premium mini-deck: logo/wordmark → browser/product surface → command/functional panel → atmosphere/campaign image → symbol/construction/badge → tagline/system promise.

### 5. Generate the brand-kit overview image

Use an available image-generation tool. Apply disciplined restraint:

- **Text:** minimal — brand name, one tagline, one URL/command, 2-5 section labels. No long paragraphs, no lorem ipsum, no dense explanations. Taglines short and specific ("Nothing random.", "Your network. Our watch.", "Build better.") — not buzzword soup.
- **Palette:** one dominant — base + primary accent + secondary accent + neutrals. Accents repeat across panels. No random rainbow, no generic purple-blue AI glow. One accent can carry the entire system.
- **Imagery:** art-directed — cinematic mountains, dusk skies, halftone clouds, textured paper, moody architecture. No stock people, no cliché robots, no random office photos.
- **Mockups:** minimal and believable — browser chrome, terminal, app icon, phone crop, card stack, badge, seal. Identity applications, not feature demos.
- **Premium details:** page numbers, alignment marks, construction lines, thin rules, one highlighted word, one accent chip. Used sparingly — detail should reward looking closer.

### 6. Match references without copying

If the user provides reference images, extract their layout rhythm, grid style, spacing, typography
scale, visual density, logo placement, image treatment, and accent color logic. Do NOT copy exact
logos, brand names, compositions, slogans, or unique visual assets. Use references as quality
training, not as templates.

**Output:** brand-kit overview image(s). Not code.
